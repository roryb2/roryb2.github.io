## The problem

Starting every analysis from a blank notebook doesn't scale, and neither does relying on senior analysts for core services.

## What I did

Built a reusable Python library on pandas, NumPy and Jupyter. Paired it with a curriculum that teaches junior analysts to deliver on their own. Also shipped production pipelines for regulatory changes across multiple Caribbean jurisdictions.
